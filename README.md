# Slow-Space Scaling dashboard

Run ledger, validation endpoints and loss curves of the end-to-end slow-space scaling arms
(MuonW, 128K → 2M). Regenerated from the cluster's run receipts by
`projects/modded-nanogpt-track3/scripts/e2e_dashboard.py` and pushed here; GitHub Pages serves
`index.html`. Numbers are single-seed run receipts, not a ranking.
